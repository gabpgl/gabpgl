## 🚀 Projects

### 🧭 NorthStar
**A fully offline productivity hub.** Task manager, time tracking, reminders and more, all in one page.
Everything lives in your browser's storage, so ***no data ever leaves your device***.
*Started in 2022 as "Productivity Pulse" (built with a friend), then completely reworked and redesigned.*
`HTML` `CSS` `JavaScript`

### ⚡ Minecraft Renewable Energy Mod
*School project (2026).* Adds **solar panels**, **batteries**, **cables**, **animated wind turbines** and **new ores** for crafting recipes.

### 🔐 Text & Image Encryptor
Encrypts and decrypts **text AND images** with *any key* and *any special character*, using SHA-256-based key handling.
Encrypt/decrypt **n times**: with the right key you always get the original back, ***zero data loss***.
Images are converted to JSON, then back to `.jpg` / `.png`.

### 🔑 Password Toolkit
A **2-in-1** password *strength checker* + *generator*.

### 🧹 Session Cleaner (`.bat`)
One click wipes cookies, temp files and session data. *Born from the pain of using a very slow computer.* 🐌

### 🛡️ Security tool deployment
Contributed to the deployment of a **security tool** in a Ministry context.

### 🎙️ Local AI setup
A small self-hosted stack with **Ollama**, **FastKokoro** (voice) and **LiteLLM**.
