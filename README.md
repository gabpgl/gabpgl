### 🚀 Projects

#### 🧭 NorthStar
A productivity hub that runs **fully offline** in your browser: task management, time tracking, reminders and more. Everything is stored locally in the browser, and **no data ever leaves your device**.
Started in 2022 as *Productivity Pulse* (built with a friend), then completely reworked and redesigned into NorthStar.
`HTML` `CSS` `JavaScript`

#### ⚡ Minecraft Renewable Energy Mod
A school project (2026) that brings renewable energy into Minecraft: solar panels, batteries, cables, **animated wind turbines**, and new ores used in crafting recipes.

#### 🔐 Text & Image Encryptor
Encrypts and decrypts **text and images** using a SHA-256-based approach with any key, and supports every special character. You can encrypt/decrypt n times and, with the right key, always get back the original with zero data loss. Images get converted to JSON and back to JPG/PNG.

#### 🔑 Password Toolkit
A 2-in-1 password strength checker and password generator.

#### 🧹 Session Cleaner (.bat)
A batch script that wipes session data (cookies, temp files...) in one click to free up space. Born from the pain of using a very slow computer.

#### 🛡️ Security tool deployment
Contributed to deploying a security tool in a Ministry context.

#### 🎙️ Local AI setup
A small self-hosted AI stack built with **Ollama**, **FastKokoro** (voice) and **LiteLLM**.
